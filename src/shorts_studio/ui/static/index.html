SHORTS STUDIO GUIDE

실행 · 설정 도움말

프로그램 실행과 다시 열기

  1. Windows 시작 메뉴에서 Shorts Studio를 찾아 실행합니다. 기본 브라우저에 이 PC 전용 작업 화면이 열립니다.
  2. 브라우저 탭만 닫았거나 화면 연결이 끊긴 경우 시작 메뉴에서 다시 실행하세요. 기존 화면이 남아 있으면 새로고침합니다.
  3. 완전히 종료하려면 화면 오른쪽 위 앱 종료를 누릅니다. 처리 중이면 종료 확인 후 작업이 취소됩니다.

화면이 계속 열리지 않으면 Windows 시작 메뉴에서 Shorts Studio가 실행 중인지 확인한 뒤 다시 실행하세요. 이 앱은 공개 웹사이트가 아니며 인터넷 주소로 원격 접속하지 않습니다.

영상 한 편 제작하기

  1. 소스: YouTube Shorts/TikTok URL을 입력하거나 파일 업로드를 선택합니다. URL은 제작 시작 시 다운로드합니다.
  2. 화면 설정: 여백 추가는 원본 화면을 보존하고, 중앙 Crop은 화면을 채웁니다. 결과 경로를 비우면 Videos\ShortsStudio에 자동 저장합니다.
  3. 문자 제거 시작을 누릅니다. 하단에서 진행률을 확인하고, 완료 후 MP4 미리보기와 원본 / 제거 결과 비교를 확인합니다. 문자 제거는 필수 단계입니다.
  4. 분석·대본, 음성·자막, 상품·게시 단계를 필요한 만큼 이어갑니다. 대본을 검토한 뒤 음성 미리듣기를 하고 최종 합성하세요.

설정 창에서 준비할 항목

오른쪽 위 설정 상태를 눌러 항목을 선택하고, 저장 후 화면에 표시되는 준비 상태를 확인하세요.

  • Gemini AI 분석 · 한국어 대본: 모델을 고르고 Google AI Studio의 Gemini API Key를 입력합니다. 저장 후 Gemini 연결 확인을 누릅니다. AI 분석과 한국어 대본 생성에 사용되며 무료 quota/요청 제한이 적용될 수 있습니다.
  • 한국어 TTS · 무료 로컬: Windows 한국어 Heami 음성을 사용합니다. API Key는 필요하지 않습니다. 음성이 준비되지 않으면 Windows 설정의 시간 및 언어 → 음성에서 한국어 음성을 설치하세요.
  • 성능·자원 사용: CPU thread 상한을 설정합니다. PC 반응성을 우선하려면 1~2개와 다른 앱 우선을 권장합니다. thread 제한은 CPU 사용률을 정확한 퍼센트로 고정하지 않습니다.
  • YouTube 검색: 영상 후보 검색용 Data API Key입니다. 검색을 쓰지 않으면 비워 둡니다. 업로드 인증과는 별개입니다.
  • Coupang Partners: 파트너스 계정의 API 사용 승인과 Access/Secret Key를 발급받은 뒤 설정합니다. 계정이나 Key가 없으면 건너뛰세요.
  • TikTok Commercial API / 업데이트: 승인된 광고 참고 검색 또는 업데이트 배포를 구성할 때만 필요합니다. 기본 제작에는 비워 둬도 됩니다.

YouTube 게시와 결과 확인

  1. 대본 생성 후 제목·설명·태그 초안을 확인하고 필요하면 편집합니다. 상품 후보를 고르면 상품 링크와 제휴 고지가 설명란에 추가됩니다.
  2. 직접 업로드하려면 최종 게시 설정에서 OAuth client JSON을 등록하고 공개 범위를 확인하세요. 기본 공개 범위는 비공개입니다.
  3. 계정 연동이 아직 없으면 최종 MP4를 내려받아 직접 게시할 수 있습니다. Shorts 설명란의 일반 링크는 클릭되지 않을 수 있으며, Shopping 상품 태그는 게시 후 YouTube에서 별도로 설정해야 합니다.

문자 제거 결과에는 MP4와 함께 비교 미리보기·처리 보고서가 저장됩니다. 최종 음성 합성 결과에는 SRT 자막, WAV 음성, 합성 보고서도 제공됩니다.
